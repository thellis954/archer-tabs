AI on the new tab: the options, side by side

Checked 2026-10-28. Archer 1.11.0.

There are a few ways to get AI into the place you start browsing. Some are whole browsers, some live in Chrome's address bar or side panel, and some, like Archer, replace the new tab page. They do different jobs, and the right one depends on what you want help with.

This page describes each one from its maker's own pages. Archer is ours, so we have tried hard to be fair to the others, and to say plainly what Archer does not do.

"Can read the sites you browse" is not a score. Reading the page is what makes a sidebar or an agent useful. Archer leaves it out because its job is the new tab, and a new tab does not need it.

Which one fits

Archer, if you want the Atlas-style new tab in Chrome
One box on every new tab: type a site and go, or ask a question and it opens in ChatGPT, Claude or Perplexity with the question already typed. Switch between them with the buttons above the box. Saved prompts, favourites and recent conversations sit underneath. No account, and the extension has no server and no analytics. It is not in the Chrome Web Store yet, so you install it by hand. More on Archer as an Atlas alternative.
Chrome's own new tab, if Google is all you need
Nothing to install. Google's help center says the new tab has an AI Mode button beside the search box, which is still rolling out and may not be available to you yet. For questions about the page you are on, Google offers Gemini in Chrome, also rolling out; its auto browse agent is for eligible Google AI Pro and Ultra subscribers in the US.
Perplexity Comet, if you want a whole AI browser
Comet is a full browser built around Perplexity's assistant, which can take on tasks across your tabs. Perplexity made it free to download in October 2025, and it is available for Mac, Windows, iOS and Android. Moving to it means moving browsers, which is a bigger change than adding an extension.
OpenAI's ChatGPT extension, if you want ChatGPT beside every page
OpenAI's ChatGPT extension puts ChatGPT in a side panel that can summarize and answer questions about your tabs and carry out browser tasks with your permission. This is where OpenAI moved the Atlas sidebar and agent ideas, along with the ChatGPT desktop app (TechCrunch). It does not change your new tab, so it can be used alongside Archer.
OpenAI's ChatGPT search extension, if you want ChatGPT in the address bar
The ChatGPT search extension makes ChatGPT search Chrome's default search engine, so whatever you type in the address bar goes to ChatGPT. You need to be logged in to chatgpt.com, and typing !g before a query sends it to Google instead. It replaces your search engine for everything; Archer leaves your search engine alone and lets you choose per question.

What about ChatGPT Atlas?

OpenAI launched Atlas on macOS on October 21, 2025, as "a new web browser built with ChatGPT at its core". Its new tab let you "ask a question or enter a URL", and it had an Ask ChatGPT sidebar, optional browser memories, and an agent mode in preview for paid plans.

On July 9, 2026 OpenAI announced it was shutting Atlas down and moving its browsing features into the ChatGPT desktop app and a ChatGPT extension for Chrome (TechCrunch). OpenAI's help center gave August 9, 2026 as the date Atlas would stop working, and now says Atlas "has been retired and no longer receives updates".

If what you miss is the new tab, that is what Archer is for. Read Archer as a ChatGPT Atlas alternative for what carries over and what does not.

Questions

Which of these is closest to the ChatGPT Atlas new tab?
For the new tab alone (one box where you ask a question or type a site), Archer is the closest in Chrome. For Atlas's other features, the sidebar that reads the page and the agent that acts on websites, OpenAI points people to its ChatGPT extension for Chrome and the ChatGPT desktop app.
Can I use more than one of these at once?
Mostly, yes. Archer only replaces the new tab page, so it can sit next to OpenAI's ChatGPT extension for Chrome or Gemini in Chrome. Chrome allows one extension to control the new tab, so Archer and another new tab extension cannot both be active. Comet is a separate browser, so it does not mix with Chrome extensions installed in Chrome.
Is Archer free?
Yes. Archer is free and open source under the GPL-3.0, with no account. The optional answers on the page use your own OpenAI API key, and OpenAI bills you for that usage directly.
Does Archer work on Windows?
Archer is a Chrome extension, so it runs in desktop Chrome rather than on a particular operating system. ChatGPT Atlas only ever shipped for macOS.
