It reads what you typed before it moves.

Most launchers look for a dot and hope. Archer runs a fixed sequence of rules against the string, and the first one that matches wins. Here is the whole sequence, in order.

  1. 1 An explicit scheme settles it

    If the string already starts with http:// or https://, you have told Archer it is a place. It goes, and no other rule runs.

  2. 2 Whitespace means it is a question

    A URL never contains a space. This single rule kills the largest class of false positives on any launcher that just hunts for a dot. vue.js tutorial and 3.5 vs 4 pricing both have dots, and both are questions.

  3. 3 Local addresses are addresses

    localhost:3000, [::1]:8080 and 192.168.1.1 navigate, over plain http rather than https, because that is what is listening. This has to be checked before the scheme rule below, since localhost:3000 and a scheme are the same shape.

  4. 4 Every other scheme is refused

    javascript:, data: and file: classify as questions, never as places. The new tab page runs in a privileged extension origin, so a javascript: URL would execute there. A unit test asserts that no combination of mode and modifier key can produce a non-http destination.

  5. 5 Userinfo is a phishing shape

    google.com@evil.com is a perfectly valid URL whose host is evil.com. Anything with an @ before the host is refused. An address that genuinely needs credentials can still be typed with an explicit scheme.

  6. 6 The registry has the last word

    What is left gets split on its dots, and the final label is looked up in the real IANA list of top-level domains. claude.ai is a place. node.js is not, because .js is not a top-level domain and never has been.

The rest of the page earns its place.

A clock, the weather, the sites you actually open, and the things you were working on. No feed, no widgets, no sponsored tiles, nothing that moves on its own.

Clock and date
With the greeting and the time zone, so a tab opened on a borrowed machine says where it thinks it is.
Weather
From a place name you type, never from geolocation, and from an API that needs no account and no key.
Favourites
Monogram tiles, drawn from the site's own name. No favicon fetch, so nothing phones out to build them.
Recent conversations
The things you asked, with the prompt that started them, ready to pick back up.

You decide where a question lands.

An address always just opens, in every mode but one. What changes is where the questions go.

Auto

Questions go to whatever you already set as Chrome's default search engine. Point that at ChatGPT, Claude, Perplexity or Google, and Archer follows without being told. It has no endpoint of its own.

The default

Answer here

The question is answered on the new tab itself, streamed from your own API key. Nothing is proxied, because there is no Archer server to proxy it through.

ChatGPT

Opens chatgpt.com with the question already in the composer.

Claude

Opens a new Claude conversation, prefilled the same way.

Perplexity

Opens a Perplexity search with the question carried over.

Search

Nothing navigates. Every string is a query, even one shaped exactly like an address. This is the sticky form of holding Cmd while you press Enter.

Two permissions at install. That is the whole prompt.

Everything else is optional and asked for at the moment you click the thing that needs it, which is the only moment your answer means anything.

Asked at install

search
Hands a question to your default engine, whatever you set it to.
storage
Your mode, your saved prompts, your launch log. Local only.

Notably absent: tabs. Retargeting the current tab does not need it, and its prompt reads “Read your browsing history”.

Asked at the click

history
Turns your recent conversations into rows. Requested when you switch them on.
api.openai.com
Requested when you save an API key, and never before.
open-meteo.com
The weather card. Requested when you save a place name, and it sends that name and nothing else.
topSites
Adds the sites you visit most to the rows.
sessions and tabs
Recently closed tabs. This pair does cost the browsing-history prompt, and the menu says so.
clipboardRead
Only for the paste item in the plus menu.

There is no Archer server, no account, and no telemetry. What you type goes to the destination you chose, the same way it would from the address bar.

About a minute, by hand.

Archer is not on the Chrome Web Store yet. Loading it unpacked works today and takes four steps.

  1. Get the source

    git clone https://github.com/thellis954/archer-tabs

  2. Turn on Developer mode

    Open chrome://extensions, then flip the switch at the top right.

  3. Load unpacked

    Pick the extension folder, not the repository root.

  4. Open a new tab

    That is it. Nothing to sign in to, nothing to configure.
