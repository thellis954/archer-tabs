It can tell a question from a website.

That is the whole trick, and you never have to think about it. Scroll through a few things you might type and watch where each one goes.

  1. A question you would normally search

    Anything that reads like a sentence goes to whichever AI you picked. No quotes, no special key, no menu. You type it and press Enter.

  2. A website you already know

    Type an address and you just land on it, exactly like the address bar. Archer does not get clever and turn it into a search.

  3. Even the ones with a dot in them

    This is where most launchers trip. They spot a dot and assume you meant a website. Archer checks properly, so node.js stays a question and claude.ai stays a website.

  4. Back and forth, all day

    The point is not any single one of these. It is that you stop deciding. One box handles both, every time you open a tab.

It is not watching you.

This is the part worth reading before you install anything, so here it is in plain words.

No account, ever

Nothing to sign up for and no password to make. Install it and it works.

No tracking, no ads

There is no company server behind Archer collecting anything, because one was never built. Nobody is counting your clicks.

It stays on your computer

Your settings and your recent questions are saved in your own browser. Uninstall it and every bit of that goes with it.

It cannot read the web pages you visit

Archer only exists on the new tab. It has no way to see the sites you browse, and it never asks for permission to.

When you send a question to ChatGPT, it goes to ChatGPT. That is the only place anything goes, and only when you press Enter. Read the full privacy policy.

Getting it, for now.

Archer is not in the Chrome Web Store yet, so there is no one-click button to press. Adding it by hand takes about five minutes and you only do it once. If that is not for you, the honest answer is to wait.

  1. Download it

    Open the project page, click the green Code button, then Download ZIP. Unzip it somewhere you will remember, like your Documents folder.

  2. Open Chrome's extensions page

    Type chrome://extensions into the address bar and press Enter. Turn on Developer mode with the switch in the top right corner.

  3. Add the folder

    Click Load unpacked, then find the folder you unzipped and choose the one inside it called extension. Not the outer folder, the one named extension.

  4. Open a new tab

    That is it. Nothing to sign in to, nothing to set up.

Want to know when it lands in the Chrome Web Store? Star the project and GitHub will tell you.
