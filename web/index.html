Ask, or go.

One box on every new tab. Type a question and it goes to your AI. Type an address and you just land there. Archer works out which you meant.

How it works

It can tell the difference

claude.ai is a place. node.js is a question. Most launchers get that wrong because they look for a dot — Archer checks the real registry of top-level domains, and treats anything with a space as a question.

Your search engine, not ours

Questions go to whatever you already set as Chrome's default engine. Point that at ChatGPT, Claude, Perplexity or Google and Archer follows. It has no opinion and no endpoint of its own.

Quiet by default

No feeds, no widgets, no weather, no sponsored tiles. A mark, a box, and the things you were recently working on. It loads instantly because there is nothing to load.

Privacy

Archer has no server. There is nothing to sign in to, and nothing is sent anywhere except the page you asked for. What you type goes straight to the destination you chose, the same way it would from the address bar.

The extension asks Chrome for one permission — search — so it can hand a question to your default engine. Later versions will offer to read your browsing history so recent conversations can appear on the page; that is opt-in, stays on your machine, and is never uploaded.

Install

Archer is not on the Chrome Web Store yet. Until then it takes about a minute to load it yourself.

  1. Download the repository, or git clone https://github.com/thellis954/archer-tabs
  2. Open chrome://extensions and turn on Developer mode
  3. Click Load unpacked and pick the extension folder
  4. Open a new tab

Want questions to go to ChatGPT from the address bar too? Install OpenAI's ChatGPT search extension — it sets your default engine, and Archer follows it.
