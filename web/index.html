Five minutes, once.

Archer is not in the Chrome Web Store yet, so you add it yourself. Four steps, and you never do it again.

  1. Download it

    Open the project page, click the green Code button, then Download ZIP. Unzip it somewhere you will remember, like your Documents folder.

  2. Open Chrome's extensions page

    Type chrome://extensions into the address bar and press Enter. Turn on Developer mode with the switch in the top right corner.

  3. Add the folder

    Click Load unpacked, then find the folder you unzipped and choose the one inside it called extension. Not the outer folder, the one named extension.

  4. Open a new tab

    That is it. Nothing to sign in to, nothing to set up.

Star the project and GitHub will tell you when it hits the Chrome Web Store.
