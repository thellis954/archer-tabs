After Atlas

A ChatGPT Atlas alternative for the new tab

Written 2026-10-28. Archer 1.11.0.

ChatGPT Atlas has been retired. OpenAI announced on July 9, 2026 that it was winding down its Atlas browser, and its help center gave August 9, 2026 as the date Atlas would stop working.

Archer is a free, open-source Chrome extension that keeps one part of Atlas alive: a new tab with a single box where you can ask a question or type a site, and it works out which you meant. It runs in the Chrome you already use. It is not a browser, and it is not made by OpenAI.

What Atlas users tend to miss

Atlas launched on macOS in October 2025 as a browser with ChatGPT built in. In OpenAI's words, its new tab page let you "ask a question or enter a URL" from the same place. That one habit is the hardest to give up: open a tab, type, press Enter, and not think about whether it was a search, a question or an address.

Atlas also had a ChatGPT sidebar that could read the page you were on, optional browser memories, and an agent mode that could click around sites for you. OpenAI says those ideas are moving into ChatGPT's own desktop app and a ChatGPT extension for Chrome (TechCrunch). Archer does not try to replace any of that.

What Archer does

One box for questions and sites
Type youtube.com and you land on YouTube. Type explain the offside rule and it goes to the AI you picked. The decision uses the real list of top-level domains, the way the address bar does, and only web addresses are ever opened.
Your choice of destination
Send questions to ChatGPT, Claude or Perplexity, where they open with the question already typed. Or send them to Google or whatever search engine Chrome is set to use. One click on the buttons above the box switches it.
Answers on the page, if you want them
Add your own OpenAI API key and short answers stream onto the new tab itself, billed to your OpenAI account. You pick the model and can set a daily budget. This is optional; without a key everything else works.
The rest of a good new tab
Saved prompts you bring back with a slash, recent ChatGPT and Claude conversations under the box (if you turn that on), favourites, a clock and a weather card.

What Archer does not do

It does not read the pages you visit
There is no sidebar that chats about the current page. Archer has no content scripts and no access to the sites you browse, on purpose.
No agent, no browser memories
Archer will not click through sites for you, and it does not build a memory of your browsing.
No chatbot of its own
Questions go to the service you chose, and you use that service's own account and plan there. Archer has no account and no server.
Not in the Chrome Web Store yet
For now you install it by hand, which takes a few minutes, and updates are manual too. The steps are below.

Install it in a few minutes

Archer is waiting on Chrome Web Store review, so for now you add it yourself, once.

Download archer-v1.11.0.zip Compare the options

  1. Download it

    Get archer-v1.11.0.zip from the latest release and unzip it somewhere you will keep it, like your Documents folder.

  2. Open Chrome's extensions page

    Type chrome://extensions into the address bar and press Enter. Turn on Developer mode with the switch in the top right corner.

  3. Add the folder

    Click Load unpacked and choose the folder you unzipped: the one with manifest.json directly inside it.

  4. Open a new tab

    That is it. Nothing to sign in to.

Questions

Is Archer made by OpenAI, or a continuation of Atlas?
No. Archer is an independent open-source project. It is not affiliated with or endorsed by OpenAI, and it does not use any Atlas code.
Does it bring back my Atlas bookmarks or history?
No. Archer has nothing to do with Atlas data. If you exported your bookmarks from Atlas, OpenAI's retirement article explains how to import them into Chrome.
Do I need a ChatGPT account or an API key?
Not for Archer. Questions open on chatgpt.com, claude.ai or perplexity.ai, which work the way they always do, signed in or not. An OpenAI API key is only needed for answers on the page.
Is it free?
Yes. Archer is free and open source under the GPL-3.0. If you use your own OpenAI key, OpenAI bills you for that usage directly.
What does it collect?
The extension has no server, no analytics and no telemetry. Your settings and prompts stay in your browser. The privacy policy lists exactly what leaves the device and when.
Does it work on Windows?
Atlas only ever shipped for macOS. Archer is a Chrome extension, so it runs in desktop Chrome rather than on a particular operating system.
Does it work in other browsers?
It is built and tested for desktop Chrome. Other Chromium browsers are not tested.

Keep an eye on it

If Archer is useful to you, a star on GitHub helps other people find it. Watch the project for new releases, including when it reaches the Chrome Web Store. Bugs and ideas are welcome as issues.
